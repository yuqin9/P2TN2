# P2TN2 前置实验

验证网络流量特征分布符合帕累托定律（Pareto Principle），为 P2TN2 查找表压缩策略提供实验基础。

## 实验内容

### 1. 数据聚合帕累托实验 (`数据聚合帕累托实验/`)
直接对原始协议头部字段进行二值转换，统计特征模式频率，验证帕累托分布。
- 覆盖数据集：ISCX VPN、CTU-13、MAWI、USTC、CIC-IDS 2017、NSL-KDD、UNSW-NB15、IOT23
- 结论：少数高频特征模式（<8%）可覆盖 80% 以上流量

### 2. ISCX DNN 推断 LUT 实验 (`ISCX推断LUT实验/`)
训练 DNN 模型对 ISCX VPN 流量进行二分类，将模型推断结果构建为查找表（LUT），
验证推断后的特征模式仍符合帕累托分布。
- 数据分流：30% 训练 / 10% 测试 / 60% LUT 聚合 + 100万扩展
- DNN 准确率 97.88%，LUT 命中率 96.9%，LUT 准确率 95.41%

## 代码

- `pareto_analysis.py` — 数据聚合帕累托分析
- `iscx_expand_lut.py` — DNN 训练 + LUT 推断 + 帕累托分析
